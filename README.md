# Taskflow

A simple task management application built as a personal learning project.

## Features

- Add and manage tasks
- Mark tasks as completed
- Filter tasks by status

## Tech Stack

- HTML
- CSS
- JavaScript
- Tailwind CSS

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.

If Tailwind CSS uses a build process, start the development
command configured in `package.json` before opening the app.
